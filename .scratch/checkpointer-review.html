Conversation memory: proposed patch

Everything below is a proposal for review only — nothing has been written to the repository. Files marked NEW show the full proposed content. Files marked MODIFIED show a line-by-line diff against what's currently on main: green = added, red strikethrough = removed. Every code block has its own copy button, which copies the clean final version of that file (diff markers included for review, excluded from the copy).

One honest flag: the new GET /chat/{thread_id} endpoint in routes/chat.py calls graph.aget_state(...) to read back stored history. That's LangGraph's documented API, but it's untested against this exact setup — it should be verified with a real run before we trust it in production.
